# Code structure

`configs/`, `src/stage/`, and `tools/` provide the compact sample workflow. `research/configs/`, `research/src/`, and `research/tools/` provide the current full experiment implementation. `sample_data/` holds sanitized graph examples and sample splits. `datasets/` describes the three dataset sources. `manifest/` contains dataset and sample manifests. Generated files belong under `outputs/workspace/` and are not included in this repository.

Start with the [repository README](../README.md), [compact workflow](compact-workflow.md), or [research workflow](../research/README.md).
