# Reproduction guide

The public repository contains source code, configuration, a sanitized graph sample, and dataset descriptions. Precomputed experiment outputs and model checkpoints are not included.

For a local code-path check on the sample, follow the [compact workflow](compact-workflow.md). For full-data training and evaluation, follow the [research implementation](../research/README.md) after obtaining the graph archives described in the [ID-APT dataset page](../datasets/ID-APT.md). The [DAPT 2020 instructions](../datasets/DAPT2020.md) use the dataset authors' public CSVs. Generated outputs should stay under `outputs/workspace/`.
