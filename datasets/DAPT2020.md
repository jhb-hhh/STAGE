# DAPT 2020

Download the [DAPT 2020 dataset](https://gitlab.com/asu22/dapt2020) from its authors and use the [CSV directory](https://gitlab.com/asu22/dapt2020/-/tree/main/csv). The benchmark code expects the ten labeled flow CSVs.

Run the following from `research/` with its dependencies installed. Point `--raw-dir` to the downloaded CSV directory and use a fresh output directory.

~~~sh
python tools/dapt_benchmark.py prepare --raw-dir data/external/dapt2020/csv --output outputs/workspace/dapt-run
python tools/dapt_benchmark.py run --output outputs/workspace/dapt-run --device cuda:0
python tools/dapt_benchmark.py summarize --output outputs/workspace/dapt-run
~~~

The protocol divides flows into time blocks, constructs overlapping graph windows, and selects model settings and decision thresholds using validation data within each fold. Generated checkpoints and metrics remain in the user's workspace and are not included in this repository.
