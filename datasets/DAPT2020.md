# DAPT 2020

Download the [DAPT 2020 dataset](https://gitlab.com/asu22/dapt2020) and use its [csv directory](https://gitlab.com/asu22/dapt2020/-/tree/main/csv). The [input manifest](../reference_artifacts/metrics/dapt2020/manifest.json) records the names, SHA-256 hashes and row counts of the ten CSVs used here.

Run the following from `research/` with its dependencies installed. Point `--raw-dir` to the directory containing the ten CSV files. Use a fresh output directory when preparing the data.

~~~sh
python tools/dapt_benchmark.py prepare --raw-dir data/external/dapt2020/csv --output outputs/workspace/dapt-run
python tools/dapt_benchmark.py run --output outputs/workspace/dapt-run --device cuda:0
python tools/dapt_benchmark.py summarize --output outputs/workspace/dapt-run
python tools/export_dapt_benchmark.py --output outputs/workspace/dapt-run
~~~

The protocol divides flows into time blocks before constructing overlapping graphs. It produces 101 graph windows. Validation selects model settings and decision thresholds within each fold. The [checked results](../reference_artifacts/metrics/dapt2020/checked_fold_metrics.csv) include confusion counts, attack-class precision/recall, macro F1, FPR and MCC. The selected checkpoint for each model and fold contains the validation selection metadata.
