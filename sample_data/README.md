# Sample Data

This directory contains a small sanitized graph subset for artifact smoke testing only.

It is not the full ID-APT dataset and should not be used to reproduce paper-scale metrics.

The sample comprises 65 graph windows in `graphs/graphs_chunk_000.pt`, [sample fold indices](splits/fold_0.json) through `fold_4.json`, and a [class map](label_mapping.json). The graph file is a PyTorch binary; download the repository ZIP from the anonymous repository page to use it locally.
