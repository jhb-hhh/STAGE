# Included files

## Code and configuration

- `src/stage/`, `tools/`, `configs/`: compact sample implementation.
- `research/src/`, `research/tools/`, `research/configs/`: full research implementation.
- `third_party/`: upstream license and method notes.

## Data and documentation

- `sample_data/`: 65 sanitized graph examples, sample splits, and class map.
- `research/data/reference/splits/`: five full-data split-index files.
- `datasets/`: ID-APT, DAPT 2020, and external-case descriptions.
- `manifest/idapt-manifest.json`: manifest for separately distributed ID-APT graph archives.
- `docs/`, `research/docs/`: instructions and implementation notes.

Precomputed checkpoints, prediction files, metrics, and paper tables are intentionally excluded. New outputs are written to the user's local workspace.
