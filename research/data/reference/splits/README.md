# Full ID-APT split indices

The five JSON files contain fixed `train` and `test` graph-window indices for the complete ID-APT collection: [fold 0](fold_0.json), [fold 1](fold_1.json), [fold 2](fold_2.json), [fold 3](fold_3.json), and [fold 4](fold_4.json). These indices require the full graph archives described in the [dataset page](../../../../datasets/ID-APT.md). The separate 65-graph sample has its own split files in `sample_data/splits/`.
